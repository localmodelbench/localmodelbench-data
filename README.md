# localmodelbench-data

Companion data and harness code for articles on [Local Model Bench](https://localmodelbench.com)
([localmodelbench.de](https://localmodelbench.de)) — benchmarks and experiments with LLMs running
fully on local hardware.

Not every article gets an open data release; folders appear here when the underlying data has
real verification or reproduction value.

## Folders

| Folder | Article | Contents |
|---|---|---|
| [`werwolf/`](werwolf/) | *"We made 8 local LLMs play Werwolf. The liars won."* | Game-master harness (Ollama, stdlib-only) + 25 full game transcripts with per-model scoreboard. |

Each folder is self-contained — see its own README for layout, event formats, and how to reproduce.
